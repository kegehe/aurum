# 测试与验收清单

## 自动化测试

当前自动化测试集中在后端核心逻辑，运行命令：

```bash
pnpm test
```

覆盖范围：

- 搜索筛选条件构建：
  - 默认排除软删除资源。
  - `includeDeleted` 包含回收站资源。
  - `deletedOnly` 仅返回回收站资源，且优先于 `includeDeleted`。
  - 关键词跨字段搜索。
  - 类型、分类、收藏、大小范围筛选。
  - 默认和显式排序。
- 处理任务：
  - 任务分页列表。
  - 任务统计透传。
  - 失败任务重试。
  - 缺失、已完成、处理中任务的错误重试。
- 批量资源操作：
  - 批量移动分类成功/失败计数。
  - 批量收藏成功/失败计数。
  - 批量软删除成功/失败计数。
  - 批量下载无资源错误。
  - 批量下载 ZIP 流、缺失资源计数和存储读取错误传播。
  - 重新处理资源时创建处理任务并返回 processing 状态。
- 批量 DTO：
  - 空资源列表拒绝。
  - 合法收藏批量 payload 通过。
- 资源服务与仓储：
  - 永久删除、清空回收站的文件/数据库删除顺序。
  - 资源重新处理后的任务入队与处理状态同步。
- 上传：
  - 已删除分类/竞态外键错误的可读报错。
- 外部资源接入：
  - 来源配置 CRUD 与策略门禁。
  - 链接导入任务与 SSRF 防护（SafeUrlService）。
  - Civitai 连接器与定时自动同步（分页游标、幂等 upsert、审核门禁、下载开关）。
  - LinkMetadata 提取、LocatorHealthChecker 健康探测调度。
  - 导入任务仓储与 IngestionScheduler。
- 样式实验室：
  - 样式分析服务、Claude Vision 客户端（mock）、本地降级分析、CSS Tokens 导出。
- AI 配置：
  - 多配置管理、生效项切换、密钥掩码。
- 设计运营台：
  - 设计文档/版本/候选/ChangeSet 原子发布、schema 校验、内部调用守卫、URL 参考治理、受控渲染快照与视觉 diff。
- 处理任务与临时文件清理工具。

## 静态验收

运行命令：

```bash
pnpm --filter @aurum/api typecheck
pnpm --filter @aurum/web typecheck
pnpm lint
pnpm build:api
pnpm build:web
```

验收标准：

- API 与 Web TypeScript 类型检查通过。
- ESLint 无错误。
- API 与 Web 生产构建通过。

## 手动验收流程

以下流程需要启动本地 API 和 Web：

```bash
pnpm dev
```

核心流程：

1. 上传图片资源，确认资源出现在资源库。
2. 打开资源详情，确认基础信息、下载和预览入口可用。
3. 给资源设置分类，确认列表筛选能找到该资源。
4. 在资源库选择多个资源，执行：
   - 全选当前页。
   - 批量移动文件夹。
   - 批量收藏与取消收藏。
   - 批量下载 ZIP。
   - 批量删除到回收站。
5. 进入回收站，恢复资源。
6. 再次删除资源，执行彻底删除。
7. 打开处理任务页，筛选失败任务并执行重试。
8. 在「来源」页配置 Civitai 来源并启用自动同步，在「导入」页创建链接导入任务，确认资源带来源信息入库。
9. 在「设置 → AI 配置」保存密钥并测试连通性，到「样式实验室」上传图片确认分析结果与导出。
10. 打开仪表盘，确认资源总数、存储占用、失败任务等统计可显示。
