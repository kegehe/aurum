# 测试与验收清单

## 自动化测试

当前自动化测试集中在后端核心逻辑，运行命令：

```bash
pnpm test
```

覆盖范围：

- 搜索筛选条件构建：
  - 默认排除软删除资源。
  - `includeDeleted` 包含回收站资源。
  - 关键词跨字段搜索。
  - 单/多标签 AND 与 OR 筛选。
  - 类型、分类、收藏、大小范围筛选。
  - 默认和显式排序。
- 处理任务：
  - 任务分页列表。
  - 任务统计透传。
  - 失败任务重试。
  - 缺失、已完成、处理中任务的错误重试。
- 批量资源操作：
  - 批量移动分类成功/失败计数。
  - 批量收藏成功/失败计数。
  - 批量软删除成功/失败计数。
  - 批量添加/移除标签。
  - 批量下载无资源错误。
  - 批量下载 ZIP 流、缺失资源计数和存储读取错误传播。
  - 重新处理资源时创建处理任务并返回 processing 状态。
- 批量 DTO：
  - 空资源列表拒绝。
  - 空标签列表拒绝。
  - 合法收藏批量 payload 通过。
- 集合批量操作：
  - 批量加入集合成功计数。
  - 集合不存在时拒绝批量加入。
  - 空批量加入资源列表拒绝。

## 静态验收

运行命令：

```bash
pnpm --filter @resource-service/api typecheck
pnpm --filter @resource-service/web typecheck
pnpm lint
pnpm build:api
pnpm build:web
```

验收标准：

- API 与 Web TypeScript 类型检查通过。
- ESLint 无错误。
- API 与 Web 生产构建通过。

## 手动验收流程

以下流程需要启动本地 API 和 Web：

```bash
pnpm dev
```

核心流程：

1. 上传图片资源，确认资源出现在资源库。
2. 打开资源详情，确认基础信息、下载和预览入口可用。
3. 给资源设置分类和标签，确认列表筛选能找到该资源。
4. 创建集合，将资源加入集合，进入集合详情确认资源展示。
5. 在资源库选择多个资源，执行：
   - 全选当前页。
   - 批量添加标签。
   - 批量移除标签。
   - 批量加入集合。
   - 批量移动文件夹。
   - 批量收藏与取消收藏。
   - 批量下载 ZIP。
   - 批量删除到回收站。
6. 进入回收站，恢复资源。
7. 再次删除资源，执行彻底删除。
8. 打开处理任务页，筛选失败任务并执行重试。
9. 打开仪表盘，确认资源总数、存储占用、失败任务、集合数量等统计可显示。
